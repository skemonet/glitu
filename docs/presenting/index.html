Presenting

Keyboard shortcuts, the speaker view with notes and timer, rehearsals, synchronized windows, a phone as a remote control, drawing on slides and the scroll view.

Keyboard shortcuts

? shows this list during the presentation.

On a touch screen, swipe with one finger to change slides, and use two fingers to zoom and pan. The mouse wheel changes slides when the theme's glitu.yaml sets mouseWheel: true.

Speaker view

S opens the speaker view in a separate window. It shows the current slide as the audience sees it, the next step, the notes, the clock and a timer. The passage of the notes that matches the current click is highlighted (see [click] in Writing slides).

All the shortcuts work in the speaker view, so you can drive the presentation from it. Drag the separators to resize the columns and use A− A+ to change the size of the notes; the browser remembers the layout. The timer survives a reload or a closed speaker window, and ⋯ resets it or changes the layout.

Timing and rehearsals

A planned duration is written at the end of a slide title:

## Live demo ⏳95🏃3

The slide is planned for 95 seconds, averaged over 3 rehearsals (🏃3 is optional). Under the current slide, the speaker view lists the planned and actual time of every slide, and its bottom bar shows whether you are ahead of or behind schedule.

To time a rehearsal, run glitu server, open the speaker view, then choose ⋯ → Rehearse from the start (or from here). ↺ restarts the current slide and ⏸ pauses. Finish shows the time measured for each slide and what to do with it: average it with the previous rehearsals (the default), replace the planned duration, or skip it. glitu then writes the durations into the slide titles of the Markdown file, so save your edits first.

Synchronized windows and remote control

Under glitu server, every window that shows the presentation stays on the same slide: projector, laptop and tablet follow each other.

To use a phone as a remote control, allow your local network when starting the server:

glitu server --allow 192.168.0.0/16

Then open the address shown, followed by ?remote, on the phone. The remote shows the current slide, two large buttons and the notes, and joins the presentation where it is. ?follow shows the presentation in sync, without the buttons.

Drawing

D turns the slide into a drawing surface for the mouse, a finger or a stylus. Keys 1 to 5 choose the colour, Z undoes, X clears, and D or Esc leaves. The drawings stay with their slide and the browser keeps them from one session to the next.

Scroll view

Adding ?view=scroll to the address shows the slides one below the other, at the width of the window, with every step visible: the presentation reads like a web page. Phones (windows narrower than 435 px) get this view by default, except as a remote; in landscape, they switch back to the presentation.

Printing

Adding ?print-pdf to the address lays out one slide per page with every step visible; print it to PDF from the browser. glitu build pdf -o talk.pdf does the same from the command line: see Building and exporting.
