# "black" theme

The default theme of reveal-md: `black.css` and its fonts (reveal.js 5.1.0, MIT), `reset.css`
(reveal.js) and the `zenburn.css` highlighting (highlight.js, BSD-3). reveal-md's settings in
`glitu.json`: 960 × 700, 4 % margin, centred slides, arrows, progress, number, and a 2D slide
transition (reveal-md's default, a 3D rotation, is left out). Chosen by default for a markdown
written with reveal-md's rules (slides separated by `---`); `theme: <name>` in the front matter
chooses another one ("white", its light counterpart).
