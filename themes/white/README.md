# "white" theme

reveal.js's white theme, the opposite of "black": `white.css` and its fonts (reveal.js 5.1.0, MIT),
`reset.css` (reveal.js) and the `zenburn.css` highlighting (highlight.js, BSD-3), with the same
settings as "black" in `glitu.json` (960 × 700, 4 % margin, centred slides, arrows, progress,
number, 2D slide transition). `theme: white` in the front matter chooses it.
